# 学习资源推荐

> 都是我们真正看过、并且在这项目里用上的。带一句话说明「为什么值得看」。

## 一、MCP 协议

| 资源 | 链接 | 为什么推荐 |
|---|---|---|
| MCP 官方文档（入门） | https://modelcontextprotocol.io/docs/getting-started/intro | 课程资料里的那篇，先建立协议整体印象：host / client / server 各是什么 |
| MCP 规范全文 | https://modelcontextprotocol.io/specification/latest | 想知道 `tools/list` 到底长什么样、为什么根节点必须是 `{"type":"object"}`，只能看规范 |
| **MCP Python SDK 文档** | https://py.sdk.modelcontextprotocol.io/ | **本项目最重要的参考**。注意看 **What's new in v2** 和 **Migration Guide** 两页，1.x→2.x 的改名全在里面 |
| MCP Inspector | https://github.com/modelcontextprotocol/inspector | 一个网页版调试器，能直接看到服务端暴露了哪些工具、参数 schema 长什么样。`mcp dev server.py` 会拉起来 |
| 《MCP 协议深度解析与实战应用》 | https://zhuanlan.zhihu.com/p/1931356753280344290 | 课程资料里的实战文，中文讲解协议栈比较清楚 |

> ⚠️ 一个真实提醒：网上绝大多数 MCP 教程还是 1.x 的写法（`FastMCP`）。照着写会直接 `ModuleNotFoundError`。**以官方 v2 文档为准。**

## 六、我们踩坑后额外补充的

这几条不在任何「MCP 入门」清单里，但对我们帮助最大：

1. **永远先打印依赖版本**。我们的 `scripts/check_env.py` 第一屏就打印 `mcp` 版本，就是这个习惯的产物
2. **看 PyPI 上的 release 时间**。`mcp` 2.3.0 是 2026-10 发布的，很多教程写于 1.x 时代
3. **官方文档站点通常有 `llms.txt`**。`https://py.sdk.modelcontextprotocol.io/llms.txt` 是整站索引，比翻侧边栏快
4. **pydantic 模型不能直接迭代**。`for x in model` 拿到的是 `(字段名, 值)`，要用 `model.field`
