# 答辩演示脚本

> 目标：8~10 分钟讲完，**全程不依赖网络和 API Key**，并证明「真的走了 MCP」。
>
> 演示前 5 分钟必做：`python scripts/check_env.py`，确认 MCP 握手成功、字体可用。

## 准备

```bash
cd 3124004444
.venv\Scripts\activate

# 提前跑一遍，确保 data/state 里有历史文件（第 6 步要用）
python -m agent.ui.cli --demo
```

把终端字号调到 14~16，窗口拉大——图片会用 ASCII 预览打在终端里。

## 第 0 步：先讲清楚这是什么（1 分钟）

> "我们要展示的不是一个聊天框，而是一个**把自然语言变成真实动作**的系统。
> 它有两个大脑可选（规则式 / 大模型），两条工具通道（MCP 协议 / 进程内），
> 现在这台机器上**没有 API Key、也没有联网**，依然能完整演示。"

打开终端：

```bash
python scripts/check_env.py
```

指三行：`mcp 2.3.0`、`协议版本 2026-07-28`、`握手成功 暴露 8 个工具`。

## 第 1 步：算数（30 秒）

```bash
python -m agent.ui.cli -c "算一下 (12+8)*3/5 保留两位小数"
```

预期：`calculate(precision=2, expression='(12+8)*3/5')` → `= 12`

> "注意它不是 `eval`。我们自己做 AST 解释，只认数字常量和四则运算。"

补一句安全性（评委常问）：

```bash
python -m agent.ui.cli -c "算一下 __import__('os').system('dir')"
```

预期：被拒绝，提示"只能做四则运算"。

## 第 2 步：核心亮点——多步任务（2 分钟）

```bash
python -m agent.ui.cli --channel mcp
```

在交互里输入：

```
帮我查上海未来三天天气，然后画成柱状图
```

要指着屏幕讲三件事：

1. **两次工具调用**，不是一次
2. 第二次的 `labels` / `values` **就是第一次返回的数据**
3. 结果行末尾的 `·mcp` —— 说明这次调用穿过了一个 stdio 子进程

如果评委追问"怎么证明真的走了 MCP"：

```bash
tasklist | findstr python
```

会看到多一个 python 进程（MCP 服务端）。或者：

```
/trace
```

看 `channel: mcp`。

## 第 3 步：出图能力（1.5 分钟）

```
画个梗图：周五了，代码还没写完
```

等 ASCII 预览打出来。

```
做一张恐龙海报，上面写 Milk Dragon
```

> "这些小恐龙是用 Pillow 的椭圆和多边形逐块画的，没有用任何第三方卡通素材。"

## 第 4 步：多轮补槽（1.5 分钟）

```
天气怎么样
```

预期反问：`你想查哪个城市的天气呀？`

```
北京
```

预期：直接查北京天气（**没有重新问一遍"你要干嘛"**）。

> "这就是多轮。上一轮欠的槽位存在 memory 里，下一轮先尝试续接。"

## 第 5 步：失败自纠（1 分钟）

```
记一下：交作业 明天
```

如果日期解析失败，它会去掉日期重试一次并成功。

> "工具报错不是终点，是下一轮规划的依据。"

## 第 6 步：跨轮引用 + 文件（1 分钟）

接着上一步（同一会话里）：

```
把刚才的天气存成 weather.md
```

然后：

```
看看有哪些文件
```

> "它把上一轮的工具结果写成了磁盘上的真文件，路径受限在 `data/files/` 沙箱内。"

## 第 7 步：断网降级（1 分钟）

另开一个终端：

```bash
python -m agent.ui.cli --no-network -c "杭州天气"
```

预期出现：`（注意：这是离线示例数据，不是实时天气哦）`

> "我们宁愿如实标注，也不假装数据是实时的。"

## 第 8 步：网页端（1 分钟，可选）

```bash
streamlit run agent/ui/web_app.py
```

指两处：
- 侧栏的工具清单是**动态发现的**（删掉一个工具，侧栏就少一个）
- 工具卡片上的 `·mcp` 标记

## 可能被问到的问题

| 问题 | 怎么答 |
|---|---|
| 为什么不用 LangChain？ | 我们要讲清楚每一步，不想藏在框架里；而且 MCP 是课程推荐的协议，官方 SDK 足够 |
| 规则式规划器是不是玩具？ | 51 条中文说法的表驱动测试，准确率 100%；打分公式每项可解释，`--debug` 能打明细 |
| 没有大模型怎么算智能体？ | 决策在我们自己代码里，大模型只是可选增强。换 `LLMPlanner` 主循环一行不改 |
| 安全性怎么保证？ | 计算器 AST 白名单（18 条恶意用例）、文件路径白名单沙箱（35 条绕过用例），都有单测 |
| 为什么盯 mcp 2.3 这么死？ | 2.x 和 1.x API 不兼容，`FastMCP` 已删除。锁版本 + 自检脚本首屏打印版本，避免"别人机器上装完就跑不起来" |
| 最难的地方？ | MCP 2.x 文档与教程不一致；Windows 起子进程需要 Proactor 事件循环；Streamlit 里不能 `asyncio.run()` |
